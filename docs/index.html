GC-MS retention-time alignment

Five batches. One shared clock.

Gas chromatography runs drift: the same compound leaves the column minutes earlier or later depending on when the batch was measured. Instead of aligning batches two at a time, this project fits one monotone warp per batch into a shared retention-time frame, using spectral anchors from every cross-batch sample pair at once.

03 — THE METHOD

One warp per batch, into one shared clock

Every batch k gets a single monotone map fk(t) = t + dk(t) into a latent retention-time axis. A warp between any two batches is fl−1 ∘ fk, so all the pairwise warps are consistent by construction, and a pair with few anchors borrows strength from the others.

Harvest anchors

Peaks on the raw TIC are matched by mass spectrum between every cross-batch sample pair, with sub-bin refinement: anchors.

One warp per batch

Drift dk is piecewise linear on 41 knots; slopes are bounded to 0.5–2, so every warp is strictly monotone.

Fit them jointly

One bounded least-squares problem over all anchors, with Huber then Tukey reweighting so mismatched compounds are rejected.

Choose smoothness honestly

λ is picked by held-out anchor error on whole retention-time windows. TIC correlation is never used to tune anything.

07 — UNCERTAINTY

Confident bands, honestly calibrated

Resampling samples within each batch and refitting 200 times gives a band around every warp. Those bands are narrow, and the predictive intervals built from them cover fewer held-out anchors than they should, so they need calibration before anyone relies on them.

Band width along the run

Width of the 90 % bootstrap band for each batch pair (minutes). Hover for values.

Held-out coverage

Share of held-out anchors inside their 90 % interval.

Warp-only bands capture estimation noise, not the scatter of individual anchors; even with that scatter added, coverage falls short of 90 %. A conformal rescaling is the obvious next step.
08 — FAIR BENCHMARK

Every method, the same yardstick

Published numbers mix protocols: some methods warp only A, some resample both batches, some fit a separate warp for every sample pair. Here each method is reduced to the map it estimates (RT in B → RT in A) and scored two ways: in B's frame, and in the frame halfway between the batches.

09 — CAVEATS

What these results do and don't show

Five batches, one study

Batch is confounded with species and tissue, and aug2015 has two samples. A dataset with more batches and repeated QC samples is needed.

TIC r is a proxy

Correlation of total ion chromatograms rewards overlapping peaks, not correct compound identities. Held-out anchor error is reported alongside it.

Under-covering intervals

Bootstrap bands of a regularised fit miss its bias. Predictive coverage is against a 90 % target.

End-of-run anchors

Late, bleed-like peaks with similar spectra produce conflicting anchors; the robust fit rejects them, so the last minutes rest on extrapolation.

10 — TRY IT

Run it on synthetic data with a known answer

The fish oil chromatograms are private, so the repository ships a generator for a public stand-in: five batches with the same names and design, drifts shaped like the real ones (two batches eluting 2.5–5 min early, growing along the run), staggered acquisition starts and column bleed. The true drift of every batch is saved next to the data, so you can check that the joint model recovers it.

# shared code: the gcmsalign package
pip install "gcmsalign @ git+https://github.com/woodRock/warp-align.git"
git clone https://github.com/woodRock/joint-align && cd joint-align

# 31 chromatograms, 5 batches, true drifts in truth.json
python scripts/00_make_synthetic_data.py
# joint model on it, ~1.5 min
python scripts/30_multibatch_align.py --data data/synthetic \
    --results results/synthetic --figs figs/synthetic
# every method, same protocols, ~1 min
python scripts/32_fair_benchmark.py --data data/synthetic \
    --results results/synthetic --neural-steps 300

What to expect

On the synthetic batches the joint warps land within about 0.1 min of the true drift wherever compounds exist in both batches (checked in tests/test_pipeline.py). Beyond the last compound of a batch the warp is an extrapolation.
